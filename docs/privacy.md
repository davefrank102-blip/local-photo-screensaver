# Privacy

- Photos remain on the companion PC/NAS
- No analytics, accounts, or cloud sync in this project
- Roku receives only opaque IDs + image bytes over your LAN
- Admin folder browsing never leaves the PC (localhost)
- Junk “Delete” permanently removes local files you confirm

This is intentionally local-first. If you need internet exposure, wait for a future authenticated release — do not port-forward the MVP server.
