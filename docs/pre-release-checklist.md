# Pre-release checklist

See project chat / maintainer notes. Minimum before tagging a release:

- [ ] Cold start server + admin UI
- [ ] Sideload on at least one Roku Ultra and one Stick
- [ ] Playlist + paging + shuffle/order
- [ ] EXIF upright check
- [ ] Firewall / phone playlist URL
- [ ] Server down / wrong IP show errors (no device freeze)
- [ ] README paths and release assets match
